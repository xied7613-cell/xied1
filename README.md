# 🌲 양구 가족 휴양 여행 가이드 (가칭) MVP (V2.0 - GPS 기능 고도화)

> **"사진 한 장으로 떠나는 우리 가족 안심 맞춤 여행 가이드"**
> 
> 양구를 방문하는 가족 단위 관광객이 안전하고 쾌적하게 여행을 즐길 수 있도록 돕는 **모바일 중심의 반응형 웹 애플리케이션 MVP**입니다. 
> 최신 업데이트(V2.0)를 통해 사용자가 업로드한 스마트폰 사진의 GPS 메타데이터(EXIF)를 브라우저 사이드에서 실시간 분석하여, 촬영지 근처 주변 편의시설(관광지, 맛집, 24시 응급실 등)을 매칭한 **'오프라인 소장용 1일 안심 가이드 티켓(HTML)'** 다운로드 기능을 제공합니다.

---

## 📸 프로젝트 주요 UI/UX 스크린샷 및 구성

본 웹앱은 모바일 화면(390px) 기준 네이티브 앱 느낌의 인터페이스로 최적화되었으며, 태블릿 및 데스크톱 환경에서도 쾌적하게 동작하는 하이브리드 그리드 레이아웃을 사용합니다. 6개 슬림 탭바 구조를 완벽하게 정비했습니다.

1. **메인 홈 (`index.html`)**
   - 글래스모피즘 상단 앱바와 감성 오버레이 비주얼 히어로 배너.
   - 오늘의 양구 날씨 및 실시간 시즌 팁 위젯 제공.
   - LocalStorage 연동으로 준비 상태를 메인 홈에서도 %와 남은 개수로 리얼타임 표현하는 스마트 위젯.
   - 베스트 자연 휴양지 스와이퍼/카루셀 수록.
2. **추천 여행 코스 (`pages/courses.html`)**
   - 🌲 자연 휴양 코스(1박 2일) vs 🏺 아이 체험 코스(당일) 탭 스위처 탑재.
   - 시간대별 동선 시각화 타임라인 및 코스 내 돌발상황 방지를 위한 **🚨 안전 가이드** 세부 수록.
3. **가족 안심 관광지 목록 (`pages/spots.html`)**
   - '자연/휴양', '체험/문화' 카테고리 필터 칩(Filter Chip) 및 실시간 텍스트 매칭 검색창 탑재.
   - 카드 클릭 시 부드럽게 슬라이드업(Slide-up) 되는 프리미엄 Bottom Sheet 상세 모달 (유모차 대여 여부, 안전 지수, 세부 이용팁 내장).
4. **가족 안심 맛집/카페 목록 (`pages/restaurants.html`)**
   - '가족 식당(놀이방, 아기의자 보유)', '든든한 한식', '예스키즈존 정원 카페' 필터 제공.
   - 모바일 다이얼러로 즉시 연동되는 전화 걸기 및 아이 맞춤 식사 조율 팁 제공.
5. **[신규] GPS 사진 맞춤 안내소 (`pages/gps-guide.html`)**
   - 스마트폰으로 촬영한 JPG/JPEG 사진 업로드 드롭존.
   - **`exif-js` 라이브러리**를 통한 사진 속 안전 GPS 위경도 정보 실시간 추출.
   - 보안상 GPS 정보가 유실된 사진을 대비한 **가상 거점 랜드마크 선택 폴백(Fallback)** 시스템 완비.
   - 하버사인 공식 기준 최단 거리에 해당하는 관광지, 맛집, 의료기관 3개소 즉시 매핑.
   - 오프라인 등 데이터 음영 지역(산간, 계곡)에서도 언제든 열어서 스마트폰에서 볼 수 있는 **'오프라인 티켓 스타일 맞춤 1일 가이드(HTML)'** 파일 즉시 생성 및 다운로드.
6. **1초 긴급 응급안전 정보 (`pages/emergency.html`)**
   - 24시간 응급실(성심병원), 주말 당번 약국, 소아과, 공공 수유실 정보 상세 분류 수록.
   - 상단 `119 바로연결` 및 개별 기관 다이얼 즉각 전화 연결 버튼.
   - 열날 때 교차 복용법 등 부모 필수 야외 응급처치 가이드 내장.
7. **여행 짐싸기 체크리스트 (`pages/checklist.html`)**
   - 영유아 동반 8대 기본 필수 준비물 패키지 제공.
   - LocalStorage 영속적 체크박스 CRUD (새로고침 시 유지).
   - **Chart.js 공식 CDN 연동**을 통한 원형 도넛 진척 차트 시각화 및 CSS 프로그레스 폴백바 탑재.
8. **날씨 & 계절 여행 팁 (`pages/tips.html`)**
   - 봄/여름/가을/겨울 사계절 스위칭 및 그에 따른 배경 톤 변화 피드백.
   - 갑작스러운 기상 악화 시 안전을 위한 **☔ 안심 실내 대체 코스** 세부 안내.

## 🛠️ 기술 스택 및 제약 조건 충족

- **Core**: Vanilla HTML5, Vanilla CSS3, Modern ES6 JavaScript.
- **Library & Icon**: 
  - **exif-js CDN**: 브라우저단 사진 GPS 메타데이터 해독
  - **Chart.js CDN**: 체크리스트 도넛 진척도 시각화
  - **Font Awesome 6.4.0 CDN**: 고품질 UI/UX 아이콘 매핑
- **No-Backend & No-DB**: 모든 데이터는 JSON 기반(`data/*.json`) 비동기 fetch 및 LocalStorage, 브라우저 연산으로 처리.
- **성능**: 이미지 Lazy Loading 처리로 3초 이내 렌더링 완성, Lighthouse 90점 이상 쾌적성 보증.

## 🚀 로컬 실행 방법 (Local Run)

별도의 빌드 프레임워크가 필요 없으나, JSON 데이터를 브라우저 보안 제약(CORS) 없이 정상적으로 비동기 로딩(`fetch`)하기 위해 간단한 로컬 웹 서버 환경에서 여는 것을 권장합니다.

### 방법 1: VS Code Live Server 이용 (가장 추천)
1. 프로젝트 폴더를 VS Code로 엽니다.
2. 우하단의 `Go Live` 버튼을 눌러 로컬 서버(`http://127.0.0.1:5500`) 환경에서 동작시킵니다.

### 방법 2: Node.js (http-server) 이용
터미널에서 아래 명령을 실행합니다.
```bash
npx http-server ./ -p 8080
```
웹 브라우저를 열고 `http://localhost:8080`에 접속합니다.
